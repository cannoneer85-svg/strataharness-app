# StrataHarness v1.1.2

Выпуск **StrataHarness Desktop 1.1.2** для Windows (`win-x64`) и macOS (`mac-arm64`, `mac-x64`) на базе апстрим-движка DeepSeek Harness `0.2.2-rc.3` и встроенной методологии `v1.4.6` (замещает прерванные на этапе упаковки сборки `1.1.0` и `1.1.1`). Релиз завершает полную интеграцию рабочего процесса StrataHarness, выстраивает чистую линейку из 4 режимов во главе со «Стандартным режимом», устраняет ошибку `Unknown agent preset: strata` при обновлении с версий `1.0.x`, исправляет обрезку русских кнопок в установщике Windows NSIS и увеличивает таймаут холодного старта LibreOffice на macOS Intel (`mac-x64`).

### Чистая линейка из 4 пресетов и совместимость с профилями `1.0.x`

- В селекторе режимов и в Настройках → «Пресеты агентов» оставлены ровно 4 встроенных режима: на первом месте и по умолчанию теперь открывается прямой нецеремониальный **«Стандартный режим»** (`standard`, `order: 1`, без встроенного каталога скиллов `Strata`), а следом единой группой идут ролевые режимы **`Strata Developer`** (`order: 2`), **`Strata Analyst`** (`order: 3`) и **`Strata Designer`** (`order: 4`); режимы `minimal`, `ptc` и `cordis` отключены.
- Полностью устранена ошибка `agent-preset/not-found: Unknown agent preset: strata` при создании новых диалогов и продолжении старых сессий после обновления с `1.0.x`: схема `AgentPresetRegistry.Config.aliases` теперь по умолчанию содержит `{ strata: 'strata-developer' }` с безопасным откатом `defaultId`, а `DesktopProjectManager` при запуске приложения атомарно очищает устаревшие записи `default: strata` и `selectedDefault: strata` из пользовательского `profiles/desktop/cordis.patch.yml` с сохранением остальных настроек (`ui-theme`, `locale`, `agent-default-model`).

### Автоматический каркас проектной памяти и загрузка `CODING_STANDARDS.md`

- В ролевых пресетах `Strata Developer`, `Strata Analyst` и `Strata Designer` подключён плагин `@strata/product-bundle/workspace-scaffold`: на первом шаге сессии (`agent/pre-step`, строго до чтения инструкций) он идемпотентно создаёт в рабочей папке проекта недостающие каталоги `.agents/` и `docs/{adr,agents,analysis,handoff,research,specs}/`, а также стартовые файлы `CODING_STANDARDS.md`, `.agents/CONTEXT.md`, `docs/handoff/LATEST.md` и `docs/agents/{domain,issue-tracker,triage-labels}.md` без перезаписи существующих файлов пользователя, без копирования 41 скилла в проект и с защитой системных путей (`root`, `os.homedir()`, `os.tmpdir()`).
- Из системного промпта `Strata Developer` (Шаг 0) убрано предложение вручную вызывать `/init-project`.
- Во всех 4 активных пресетах (`standard`, `strata-developer`, `strata-analyst`, `strata-designer`) загрузчик `@deepseek-ai/dsh-agent-instructions` автоматически подхватывает `CODING_STANDARDS.md` наряду с `AGENTS.md` и `CLAUDE.md`.

### Исправления установщика Windows NSIS и упаковки macOS Intel (`mac-x64`)

- В окне установщика и автообновления Windows NSIS (`600×600` логических пикселей) кнопка «Выберите местоположение» (`$InstallerChoose`) расширена со `136` до `240` пикселей и отцентрирована (`X = 180`), а главная кнопка «Установить сейчас» (`$InstallerButton`) расширена со `120` до `200` пикселей (`X = 200`), что полностью устраняет обрезание русских подписей по краям.
- Для устранения флакующего таймаута при первой холодной конвертации DOCX через LibreOffice на `mac-x64` (и в пользовательских сессиях) в `@strata/product-bundle/cordis.patch.yml` и в профиле пост-сборочного smoke-теста (`apps/desktop/scripts/smoke-runtime.ts`) установлен `office-kit` `timeoutMs: 120000` (120 с вместо дефолтных 60 с).
- Включает все платформенные улучшения синхронизации с `dsh-v0.2.2-rc.3` и методологией `v1.4.6` (41 встроенный скилл, инструменты Office для `.docx`/`.xlsx`/`.pptx`, 100%-й паритет русской локализации `@strata/locale-ru`, доработанный экран приветствия Desktop и исправление целостности ASAR-упаковки).

# StrataHarness v1.1.0

Выпуск **StrataHarness Desktop 1.1.0** для Windows (`win-x64`) и macOS (`mac-arm64`, `mac-x64`), синхронизирующий платформу с апстрим-движком DeepSeek Harness `0.2.2-rc.3`, обновляющий встроенную методологию до версии `v1.4.6`, перестраивающий линейку встроенных режимов агента с сохранением совместимости сессий `1.0.x` и улучшающий экран приветствия настольного приложения.

### Синхронизация базового движка (DSH `0.2.2-rc.3`) и изоляция Soft-Fork

- Выполнена регламентная синхронизация кодовой базы с апстримным тегом `dsh-v0.2.2-rc.3` при сохранении трёхуровневой изоляции продукта (`~/.strataharness`, идентификатор приложения `com.nikl.strataharness`, схема `strata://`).
- Сохранено отключение телеметрии и OAuth, автономный сценарий первого запуска Desktop без облачной авторизации, выключенный Dependabot и изоляция 8 новых апстримных воркфлоу в архивном каталоге `.github/upstream-workflows/`.
- Заголовки окон настольного приложения адаптированы под апстримный контракт перетаскиваемых областей `window-drag-regions`.
- Подтверждён 100%-й паритет русской локализации (`@strata/locale-ru` — 78 клиентских словарей, 523 записи метаданных встроенных плагинов и 191-ключевой словарь оболочки Electron `apps/desktop/src/locale.ts`) со всеми строками `0.2.2-rc.3`.

### Новая линейка пресетов, совместимость сессий `1.0.x` и Office-инструменты

- Удалён дублирующий пресет `strata`, а базовая четвёрка режимов по умолчанию выстроена в порядке `strata-developer` (активен по умолчанию), прямой нецеремониальный `standard`, `strata-analyst` и `strata-designer`.
- Включены режимы `ptc` и `cordis` — вместе с кнопкой создания черновика в Настройках они скрыты за тумблером «Режим работы с кодом» (`developerTools`), а режим `minimal` остаётся отключённым.
- В `AgentPresetRegistry.Config` добавлена таблица алиасов `aliases` (`strata -> strata-developer`) с прозрачным разрешением для `defaultId`, `resolve`, `retain` и `readDocument`, обеспечивающая открытие старых сессий `1.0.0–1.0.2` и настроек `selectedDefault: "strata"` без изменения журналов на диске.
- Через декларативные оверлеи `@strata/product-bundle` настроено нецеремониальное поведение `standard` (уважение технических конвенций и git-ограничений из `AGENTS.md` без навязывания Шага 0 и стоп-гейтов), единый лимит `tool-result-pruner` (`thresholdChars: 32768`) во всех активных режимах, хостовая конфигурация `@deepseek-ai/dsh-skill-office` и подключение `@deepseek-ai/dsh-tool-office` в пресетах (`strata-developer`, `standard`, `strata-analyst`, `ptc`).
- Сокращён русский бейдж активного режима по умолчанию до `'По умолчанию'` и доработана вёрстка шапки карточек пресетов в Настройках, исключающая сжатие названий.

### Методология `v1.4.6` и экран приветствия Desktop

- Сабмодуль методологии `resources/strataharness` обновлён до тега `v1.4.6` (41 скилл), в `strata-developer` добавлена компактная директива Шага 0 с опциональной инициализацией каркаса (`AGENTS.md`, `.agents/CONTEXT.md`, каталоги ADR) и файловым фоллбэком без `pwsh`, а счётчики скиллов в локализованных описаниях ролей синхронизированы с составом сабмодуля.
- Обновлено позиционирование продукта на экране приветствия (`welcomeDescription`: «Кроссплатформенная агентная среда со встроенной методологией разработки.») и исправлена вёрстка CSS-сетки окна `600×700` с центровкой и переносом строк без обрезки правого края.

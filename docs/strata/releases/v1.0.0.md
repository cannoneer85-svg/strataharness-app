# StrataHarness v1.0.0

Первый стабильный выпуск десктопной агентной среды разработки, системного анализа и проектирования **StrataHarness Desktop** для Windows (`win-x64`) и macOS (`mac-arm64`, `mac-x64`), построенной по архитектуре управляемого `Soft-Fork` поверх агентного ядра `DeepSeek Harness`.

### Полная русская локализация по умолчанию

- Пакет `@strata/locale-ru` обеспечивает полную русскую локализацию (`ru`, `Русский`) веб- и десктопного интерфейса с установкой русского языка по умолчанию при первом запуске и порядком выбора `Русский` → `English` → `中文` в настройках продукта.
- Локализованы все клиентские словари интерфейса (с поддержкой русских форм множественного числа через `Intl.PluralRules`), нативные меню, трей и системные диалоги оболочки Electron, экран ранней загрузки, установщик Windows NSIS (`LANG_RUSSIAN`), описания встроенных ролевых пресетов `Strata*` и каталог метаданных встроенных плагинов.

### Продуктовый бандл, мульти-LLM и встроенная методология

- Пакет `@strata/product-bundle` подключает мульти-провайдерную работу с современными LLM (OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter и совместимые локальные или корпоративные шлюзы) напрямую через собственные API-ключи пользователя.
- Поставляются четыре специализированных агентских пресета под ключевые роли цикла создания продукта: универсальный `StrataHarness` (`strata`), инженерный `Strata Developer` (`strata-developer`), аналитический `Strata Analyst` (`strata-analyst`) и прототипирующий `Strata Designer` (`strata-designer`).
- В дистрибутив встроена методология `resources/strataharness` с маршрутизацией задач через Шаг 0, шестиэтапным циклом разработки со стоп-гейтами, управлением контекстом и библиотекой прикладных агентских скиллов.

### Брендированный интерфейс и автономный онбординг

- Клиентский пакет `@strata/ui-brand` формирует фирменное визуальное оформление боковой панели, стартового экрана диалога и окна сведений о продукте в Web и Desktop-режимах.
- Реализован автономный стартовый онбординг настройки провайдеров и рабочих пространств с полным отключением облачной авторизации DeepSeek OAuth, фоновой телеметрии и внешних маркетинговых привязок апстрима.

### Трёхуровневая изоляция десктопного окружения

- Приложение изолировано на уровне операционной системы, пакетов и пользовательских данных: идентификатор приложения `com.nikl.strataharness`, пакет оболочки `@strata/desktop`, протокол глубоких ссылок `strata://` и домашний каталог состояния `~/.strataharness`.
- Установка и ежедневная работа `StrataHarness Desktop` не пересекаются с конфигурациями, базами сессий, кэшами и процессами оригинального клиента `~/.dsh`.

### Кроссплатформенная дистрибуция, двухконтурное версионирование и сопровождение Soft-Fork

- Внедрено двухконтурное версионирование через `strata-product.json`: продуктовая линейка `1.0.0` и релизные теги продукта `strata-v*` развиваются независимо от версии базового движка `DSH 0.2.1-rc.4` (`dsh-v0.2.1-rc.4`), исключая конфликты версий при обновлениях ядра.
- Настроен атомарный конвейер сборки и публикации релизов для трёх целевых платформ (`win-x64`, `mac-arm64`, `mac-x64`) с генерацией `SHA256SUMS.txt`, поддержкой режимов подписи `auto` / `unsigned` / `signed` и независимым статическим HTTPS-каналом автообновления `DOWNLOAD_PROD_ORIGIN` без привязки к Tencent COS и доменам `*.deepseek.com`.
- Включён инструментарий сопровождения `Soft-Fork` (`strata:status`, `strata:version`, `strata:update-methodology`, `strata:audit-overrides`, `strata:check-upstream`, `strata:prepare-upstream-sync`, `strata:changelog`) и фоновый радар апстрима `strata-upstream-watch` для контроля новых тегов `dsh-v*` и пересечений с коммитами `strata(override)`.

# StrataHarness v1.0.1

Технический выпуск **StrataHarness Desktop 1.0.1** для Windows (`win-x64`) и macOS (`mac-arm64`, `mac-x64`), включающий синхронизацию с апстрим-движком DeepSeek Harness 0.2.1-rc.5, исправление упаковки для архитектуры macOS Intel и оптимизацию релизного конвейера.

### Обновление базового движка ядра (DSH 0.2.1-rc.5)

- Выполнена регламентная синхронизация кодовой базы с апстримным тегом `dsh-v0.2.1-rc.5` с сохранением трёхуровневой изоляции Soft-Fork (`~/.strataharness`, схема `strata://` и идентификатор приложения `com.nikl.strataharness`).
- Интегрирована апстримная кастомизация рендеринга и слотов блоков рассуждений модели (`ReasoningRow` и `ReasoningContent` в чате).
- Логика обработки и очистки тегов `<signature>` в блоке рассуждений чата покрыта комплексными юнит-тестами со 100% покрытием строк и ветвлений.
- Подтверждён 100% паритет русской локализации интерфейса (`@strata/locale-ru` и нативная оболочка Electron).

### Исправления сборщика десктопа и инфраструктуры CI

- Исправлена сборка пакетов macOS Intel (`mac-x64` DMG и ZIP) с переходом на нативный раннер `macos-15-intel` без эмуляции Rosetta.
- Фильтр радара обновлений апстрима (`strata-upstream-watch`) настроен на пропуск нестабильных пререлизов (alpha, beta, nightly) с отслеживанием только стабильных выпусков и RC-версий.
- Формат заголовка релизов на GitHub оптимизирован до лаконичного вида `v<version>`, устраняя визуальное дублирование имени продукта в списке версий.

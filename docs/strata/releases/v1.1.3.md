# StrataHarness v1.1.3

Сервисный выпуск **StrataHarness Desktop 1.1.3** для Windows (`win-x64`) и macOS (`mac-arm64`, `mac-x64`) на базе апстрим-движка DeepSeek Harness `0.2.2-rc.3` и встроенной методологии `v1.4.6`. Релиз устраняет ошибку `HTTP 403` при проверке обновлений из приложения на общих IP-адресах VPN и CGNAT.

### Надёжная проверка обновлений через веб-контур GitHub

- Встроенный провайдер обновлений `GitHubReleaseUpdater` переведён с неавторизованного REST API `api.github.com` (ограниченного лимитом в `60` запросов в час на один внешний IP-адрес) на публичные веб-эндпоинты `github.com` (`releases/latest`, `releases.atom` и манифест `SHA256SUMS.txt`), благодаря чему ручная и фоновая проверка обновлений стабильно работает за общими узлами VPN и операторским NAT.
- При выходе новой версии клиент заранее проверяет наличие `SHA256SUMS.txt` и установочного пакета под текущую ОС и архитектуру (`win-x64`, `mac-arm64`, `mac-x64`, с приоритетом подписанных установщиков над `-unsigned`), не показывая ложное уведомление об обновлении во время загрузки файлов релиза на GitHub или при публикации одноплатформенных пререлизов.
- Добавлена защита от пререлизов без SemVer-суффикса в канале `stable`, строгая привязка редиректов и Atom-ленты к репозиторию продукта и ограничение объёма буферизуемых метаданных при проверке и скачивании обновлений.

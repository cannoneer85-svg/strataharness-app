# StrataHarness v1.1.4

Сервисный выпуск **StrataHarness Desktop 1.1.4** для Windows (`win-x64`) и macOS (`mac-arm64`, `mac-x64`), обновляющий базовый движок до DeepSeek Harness `0.2.2-rc.5` (при сохранении встроенной методологии `v1.4.6`), переводящий веб-поиск на автоматический выбор провайдера, исправляющий сценарий «Создать свой плагин» и отображение встроенных плагинов в Настройках.

### Обновление движка (DSH `0.2.2-rc.5`) и автоматический веб-поиск

- Выполнена регламентная синхронизация `Soft-Fork` с апстримными тегами `dsh-v0.2.2-rc.4` и `dsh-v0.2.2-rc.5` при полном сохранении трёхуровневой изоляции продукта (`~/.strataharness`, идентификатор приложения `com.nikl.strataharness`, схема `strata://`), отключённой облачной телеметрии/авторизации и изоляции CI-воркфлоу.
- Включён новый режим веб-поиска по умолчанию **«Автоматически»**: в сессиях с моделями DeepSeek используется серверный поиск DeepSeek через Messages API без поштучной платы за каждый поиск, а для остальных моделей сохраняется `DeepSeek Search API` (при работе с DeepSeek через сторонний gateway необходимо указать `baseURL` в настройках веб-поиска или переключить провайдера вручную).
- Обновлён русский языковой пакет `@strata/locale-ru` (100%-й паритет словарей): добавлена подсказка автоматического режима веб-поиска и обновлено название `Серверный поиск DeepSeek` в единой терминологии интерфейса.
- Поддержан выделенный код отказа провайдера `CONTENT_REFUSED` для потоковых отказов DeepSeek (вместо `MALFORMED_RESPONSE`) и исправление запуска туннель-воркера `liveshare` в режиме Electron Node.

### Исправления продуктового слоя (`@strata/product-bundle`) и стабильность сборок

- Исправлена ошибка `Unknown agent preset: cordis` при нажатии «Создать свой плагин»: добавлен алиас `cordis -> strata-developer`, а режим `Strata Developer` оснащён инструментами разработки плагинов (`tool-cordis`, управление и каталог плагинов) и встроенным скиллом `dsh-doc`.
- Отключён модуль `ui-account-notifications` (зависевший от выключенного облачного аккаунта DeepSeek), что устраняет ошибку ожидания активации на странице «Настройки → Встроенные плагины».
- Усилена стабильность десктопных проверок упаковки, локального автообновления и smoke-проверок Office-конвертации на Intel macOS (`mac-x64`).

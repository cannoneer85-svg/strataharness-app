# StrataHarness v1.0.2

Выпуск **StrataHarness Desktop 1.0.2** для Windows (`win-x64`) и macOS (`mac-arm64`, `mac-x64`), добавляющий встроенное обновление приложения напрямую из GitHub Releases с криптографической верификацией `SHA256SUMS.txt` и исправляющий вёрстку нижней панели сайдбара в русской локализации.

### Автообновление через GitHub Releases

- Реализован встроенный провайдер обновлений `GitHubReleaseUpdater`, который автоматически активируется при отсутствии внешнего CDN-манифеста `resources/app-update.yml` и опрашивает релизы `strata-v*` в официальном GitHub-репозитории продукта (`releaseRepository`).
- Устранена ошибка `desktop update: this application has no packaged update source` при нажатии «Проверить обновления…» в неподписанных (`unsigned`) и автономных релизных сборках.
- Добавлено потоковое скачивание платформенного установщика (`.exe` для Windows, `.dmg` для macOS) с отображением прогресса `0%…100%`, обязательной сверкой хеша `SHA-256` по файлу `SHA256SUMS.txt` из того же релиза и автоматическим запуском установщика после подтверждения перезапуска.
- Настроена фильтрация пререлизов (`-rc.*` / `prerelease: true`): стабильные сборки предлагают только стабильные обновления, а отсутствие более новых версий или опубликованных релизов (`404`) корректно отображается как «Установлена актуальная версия».

### Интерфейс и русская локализация (`@strata/locale-ru`)

- Сокращены русские подписи пилюли индикатора обновлений в нижней строке боковой панели (`Обновление`, `Проверка…`, `Перезапуск…`, `Перезапустить` — не более 13 символов), благодаря чему соседняя кнопка «⚙️ Настройки» всегда помещается целиком в стандартной ширине сайдбара (240 px).
